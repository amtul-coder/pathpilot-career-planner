WHY THIS PROJECT EXISTS

Less “learn everything”.
More learn the right thing.

PathPilot is a frontend project built around a real product idea: career advice is often too broad, while beginners need a small number of concrete next steps.

The interface combines weighted skill scoring, a short learning plan, project recommendations and local progress tracking in one place.
